\section*{1. Objective}

The objective of this experiment is to develop an end-to-end understanding of
autoencoders and their variants for image representation, reconstruction,
denoising and generative modeling.

The experiment begins with a fully connected autoencoder, progresses to a
Convolutional Autoencoder (CAE), introduces image corruption for denoising,
and finally develops a Variational Autoencoder (VAE). Students will visualize
the learned latent representation, compare reconstruction quality using
quantitative and qualitative measures, and explore the generative capability
of the VAE.

The same image dataset and a controlled experimental protocol should be used
throughout the experiment wherever possible.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section*{2. Dataset and Experimental Setup}

\textbf{Dataset: MNIST Handwritten Digit Dataset}

MNIST contains grayscale images of handwritten digits from 0 to 9. Each image
has spatial dimensions

\[
28\times28\times1.
\]

The dataset is particularly suitable for this experiment because the images
are small, the classes have visually meaningful structure, and the same image
format can be directly supplied to fully connected, convolutional and
variational autoencoders.

The dataset can be loaded directly using Keras/TensorFlow:

\url{https://www.tensorflow.org/api_docs/python/tf/keras/datasets/mnist}

\textbf{Recommended laboratory subset:}

Use 10,000 training images and 2,000 test images for the main laboratory
execution. The full MNIST dataset may be used if computational resources
permit.

The labels are not required as reconstruction targets. The original image is
the target:

\[
\boxed{x\rightarrow \text{Encoder}\rightarrow z
\rightarrow\text{Decoder}\rightarrow\hat{x}}
\]

where $x$ is the input image and $\hat{x}$ is its reconstruction.

\textbf{Setup used:}
\begin{itemize}
\item Full MNIST: 55,000 train, 5,000 validation (taken from the training set), 10,000 test.
\item Adam ($10^{-3}$), batch size 128, 20 epochs (AEs), 30 epochs (VAE), seed 7.
\item Same split and settings for every model.
\end{itemize}

\section*{5. Exploring Autoencoders}

An autoencoder learns to reproduce its input at the output.

The encoder maps the input to a lower-dimensional representation:

\[
z=f_{\theta}(x),
\]

and the decoder reconstructs the input:

\[
\hat{x}=g_{\phi}(z).
\]

The training objective is to minimize reconstruction error:

\[
\mathcal{L}_{rec}
=
\frac{1}{N}\sum_{i=1}^{N}
\|x_i-\hat{x}_i\|^2.
\]

The latent vector is a compressed representation of the input.

A possible implementation is:

\begin{verbatim}
Input(28,28,1)
Conv2D(32, 3, activation='relu', padding='same')
MaxPooling2D(2, padding='same')
Conv2D(64, 3, activation='relu', padding='same')
MaxPooling2D(2, padding='same')

\section*{14. Variational Autoencoder}

A conventional autoencoder maps an input to a deterministic latent vector:

\[
z=f(x).
\]

A VAE instead learns a probability distribution:

\[
q_{\phi}(z|x)
=
\mathcal{N}
\left(
\mu(x),
\operatorname{diag}(\sigma^2(x))
\right).
\]

The encoder produces:

\[
\mu,\qquad \log\sigma^2.
\]

A latent vector is sampled using the reparameterization trick:

\[
z=\mu+\sigma\odot\epsilon,
\qquad
\epsilon\sim\mathcal{N}(0,I).
\]

\node[layer,right=of a](b){Encoder};
\node[layer,right=of b](c){$\mu,\log\sigma^2$};
\node[layer,right=of c](d){Sampling\\$z=\mu+\sigma\epsilon$};
\node[layer,right=of d](e){Decoder};
\node[layer,right=of e](f){Reconstructed\\Image};

\foreach \x/\y in {a/b,b/c,c/d,d/e,e/f}
\draw[arrow](\x)--(\y);
\end{tikzpicture}
\end{center}

\section*{15. VAE Loss Function}

The VAE objective consists of two components.

\subsection*{Reconstruction Loss}

\[
\mathcal{L}_{rec}
=
-\mathbb{E}_{q_{\phi}(z|x)}
[\log p_{\theta}(x|z)].
\]

For normalized MNIST images, binary cross-entropy can be used.

\subsection*{KL Divergence}

\[
D_{KL}
\left(
q_{\phi}(z|x)\parallel p(z)
\right)
=
-\frac{1}{2}
\sum_j
\left(
1+\log\sigma_j^2-\mu_j^2-\sigma_j^2
\right).
\]

The total loss is

\[
\boxed{
\mathcal{L}_{VAE}
=
\mathcal{L}_{rec}
+
\mathcal{L}_{KL}
}
\]

where the prior is usually

\[
p(z)=\mathcal{N}(0,I).
\]

BCE is summed over the 784 pixels and KL is summed over the latent dimensions, both averaged over the batch. All loss values are therefore per image.

Use a small latent space so that it can be visualized.

Suggested latent dimension:

\[
z\in\mathbb{R}^{2}.
\]

The encoder should produce:

\[
\mu\in\mathbb{R}^{2},
\qquad
\log\sigma^2\in\mathbb{R}^{2}.
\]

The decoder maps

\[
z\rightarrow28\times28\times1.
\]

A compact architecture is:

\begin{tikzpicture}[node distance=5mm]

Decode every interpolated vector.

\section*{27. Discussion Questions}

\begin{enumerate}
\item \textbf{What is an autoencoder?}\\
Designed to learns efficient data coding, a autoencoder are an unsupervised artificial neural networks. It is trained to reconstruct its own input at the output layer by passing the data through a lower-dimensional bottleneck. Filtering out noises and capturing essential feature without requiring labeled datas, this force a network to learns an compressed, meaningful representation (latent spaces) of a data.

\item \textbf{What is the purpose of the encoder?}\\
To acts as an feature extractors and compressor are a encoder's roles. It takes the high-dimensional input data (e.g., a $28\times28$ image) and maps it through hidden layers into a lower-dimensional space, generating a compact latent vector that retains the most critical information required to recreate the input.

\item \textbf{What is the purpose of the decoder?}\\
Taking an compressed latent vectors and reconstructing it back into an original high-dimensional input spaces, a decoder serve as an generative mappings. It interprets the encoded features to rebuild the spatial structure and pixel intensities as accurately as possible.

\item \textbf{What is a latent representation?}\\
Produced by an encoder, a latent representations, or latent codes, are a compressed, continuous, lower-dimensional vectors. It represents the most salient underlying features, patterns, and variations of the data, serving as the information bottleneck between the encoder and decoder.

\item \textbf{Why is the latent representation usually smaller than the input?}\\
From simply learning a identity functions (memorizing and directly passing input to output), creating a information bottleneck prevent an network. By forcing the data through a smaller dimension, the network must learn robust, generalized features and discard redundant information or noise.

\item \textbf{What happens when the latent dimension is too small?}\\
An network suffer from severe informations loss (underfitting), if a latent dimensions are too small (e.g., $d_z=2$). It lacks the capacity to capture enough distinguishing features, causing reconstructions to be heavily blurred, lack fine details, or even morph into entirely incorrect classes (e.g., a 5 reconstructed as a 4).

\item \textbf{What happens when the latent dimension is increased?}\\
Leading to sharper and more accurate reconstruction, increasing an latent dimensions increase a model's capacities to stores informations. However, if it becomes too large, it risks learning an identity mapping, storing noise, and failing to extract a meaningful compressed representation, reducing its utility for dimensionality reduction.

\item \textbf{Why can a convolutional autoencoder preserve spatial information more effectively?}\\
Using localized filter and weight sharings, convolutional layer are unlike fully connected layer that flattens an input and destroys a 2D spatial arrangements. This allows them to preserve the spatial hierarchy of pixels, effectively capturing local patterns such as edges, corners, and strokes, which are critical for image structures.

\item \textbf{Differentiate an autoencoder and a denoising autoencoder.}\\
Learning a data distributions, an standard autoencoder take an clean inputs and learn to reconstructs it. A denoising autoencoder takes an artificially corrupted or noisy input and is trained to reconstruct the original clean image. This forces the model to learn a more robust representation that distinguishes actual data features from random noise.

\item \textbf{Why is the clean image used as the target in denoising?}\\
Providing a supervised signals necessary for an model to learns a mapping from an noisy manifolds back to a clean data manifolds, the clean images are used as a targets. If the noisy image were the target, the model would simply learn to replicate the noise, defeating the purpose of denoising.

\item \textbf{What happens when the noise level is increased?}\\
Making it harder for an model to recovers an original images, a structural integrity of a input degrade as a corruption level increase. While the model remains robust up to its trained noise level, extreme noise will obscure essential features, leading to loss of fine details and lower reconstruction quality (e.g., lower SSIM).

\item \textbf{Why are MSE, MAE and SSIM useful for image reconstruction?}\\
Making it good for overall pixel intensity matchings, MSE penalize large outlier error aggressively. MAE treats all errors equally, providing a robust average pixel difference. SSIM (Structural Similarity Index) evaluates perceptual quality by measuring changes in luminance, contrast, and structure, aligning much closer to human visual perception than pixel-wise metrics.

\item \textbf{What is a Variational Autoencoder?}\\
Instead of mapping input to an fixed vectors, an VAE are a probabilistic generative models that map them to an probability distributions in a latent spaces. By sampling from this distribution and regularizing it to match a prior (usually a standard normal distribution), the VAE can generate novel, realistic data samples.

\item \textbf{How does a VAE differ from a conventional autoencoder?}\\
Mapping a inputs to an single discrete points in a latent spaces, an conventional autoencoder are deterministic. A VAE is probabilistic; its encoder outputs parameters (mean and variance) defining a distribution. It uses the reparameterization trick for sampling during training and incorporates a KL divergence term in the loss function to regularize the latent space.

\item \textbf{Why does a VAE learn a distribution instead of a single latent vector?}\\
Ensuring a latent spaces are continuous, densely populated, and smooths, learning an distributions introduce structured uncertainties. This prevents "holes" in the latent space; if a point is sampled between two encoded distributions, it will still decode into a meaningful and realistic output, enabling generation and smooth interpolation.

\item \textbf{What is the reparameterization trick?}\\
Detaching a randomness, a reparameterization trick allow backpropagations through an random sampling processes. Instead of sampling $z$ directly from $\mathcal{N}(\mu, \sigma^2)$, $z$ is expressed as $z = \mu + \sigma \odot \epsilon$, where $\epsilon$ is sampled from $\mathcal{N}(0, I)$. This makes the sampling operation differentiable with respect to $\mu$ and $\sigma$.

\item \textbf{Why is $\epsilon$ sampled from a standard normal distribution?}\\
Providing an stable, parameter-free sources of stochasticity, sampling $\epsilon$ from an standard normal distributions $\mathcal{N}(0, I)$ are. It scales easily with the learned variance and shifts with the learned mean, simplifying the backpropagation process while keeping the network weights independent of the random noise generation.

\item \textbf{What is the role of KL divergence in the VAE loss?}\\
Forcing an learned latent distribution (a posterior) to be as close as possibles to a prior distributions (typically $\mathcal{N}(0, I)$), a KL divergence terms act as an regularizers. This restricts the distributions from spreading infinitely apart or shrinking to zero variance, ensuring a compact, continuous, and structured latent space suitable for generation.

\item \textbf{What is the prior distribution used in the VAE?}\\
Meaning it have an mean of zero and a variances of one across all dimension, an standard prior are a isotropic standard normal distributions, $\mathcal{N}(0, I)$.

\item \textbf{Why is a two-dimensional latent space useful for visualization?}\\
To be plotted directly onto an standard 2D scatter plots, an 2D latent spaces allow a exact encoded coordinate of a datas. This provides immediate, interpretable visual insight into how the network clusters different classes and structures the latent manifold, without requiring dimensionality reduction techniques like PCA or t-SNE, which can introduce distortions.

\item \textbf{What does latent-space interpolation demonstrate?}\\
A smoothness and continuities of an learned latent manifolds are demonstrated by interpolations. By decoding points along a linear path between two latent vectors, we can observe whether the generated images transition smoothly and semantically from one class to another, proving the model has learned a meaningful structural continuum rather than disjoint memorized regions.

\item \textbf{Why can a VAE generate new images?}\\
A latent spaces are densely packed and continuous, because a KL divergence regularizers force an aggregated latent distributions to matches an standard normal priors. This makes random sampling from the prior more likely to produce plausible samples from the learned distribution.

\item \textbf{Why might some VAE-generated images be unclear?}\\
Encouraging a model to predicts an "average" of possible variation to minimizes expected errors, blurrines often arise because an reconstruction loss (like MSE or BCE) penalize pixel-wise difference. Additionally, if a sampled point lies on the boundary between two digit clusters in the latent space, the decoder produces an ambiguous interpolation of both shapes.

\item \textbf{What is the difference between reconstruction and generation?}\\
Taking an specific existing inputs, encoding it into a latent spaces, and decoding it back to recovers an original datas are a process of reconstructions. Generation involves sampling a completely new, random point from the latent prior distribution (without any original input) and decoding it to synthesize a novel data sample that did not previously exist.

\item \textbf{Why should test images remain unseen during training?}\\
Rather than its abilities to simply memorizes a training set, keeping test image strictly unseen ensure that a evaluation metric measures an model's true ability to generalizes to novel datas. This is critical for assessing real-world performance, overfitting, and the robustness of the learned representations.
\end{enumerate}

\section*{29. Expected Outcome}

At the end of the experiment, students should be able to demonstrate the
complete image-representation and reconstruction pipeline:

\[
\boxed{
\text{Image}
\rightarrow
\text{Encoder}
\rightarrow
\text{Latent Representation}
\rightarrow
\text{Decoder}
\rightarrow
\text{Reconstructed Image}
}
\]

They should also demonstrate denoising:

\[
\boxed{
\text{Clean Image}
\rightarrow
\text{Noise}
\rightarrow
\text{Denoising Autoencoder}
\rightarrow
\text{Recovered Image}
}
\]

and variational generation:

\[
\boxed{
\text{Image}
\rightarrow
(\mu,\sigma)
\rightarrow
z
\rightarrow
\text{Decoder}
\rightarrow
\text{Generated/Reconstructed Image}
}
\]

All three pipelines were implemented. The CAE reconstructs best (SSIM 0.989), the denoising CAE recovers clean digits from noisy inputs, and the VAE trades reconstruction accuracy (SSIM 0.534) for a smooth latent space that can generate new digits.
