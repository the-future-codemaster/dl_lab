# Experiment 7: End-to-End Study of Autoencoders and Variational Autoencoders

## Folder Structure
- `Lab7.ipynb`: Source code for Experiment 7.
- `Experiment_7.tex`: LaTeX source code for the experimental report.
- `Experiment_7.pdf`: Compiled PDF report of the experiment.
- `README.md`: This documentation file.

## Dataset Information
- **Name:** MNIST Handwritten Digit Dataset
- **Instances:** 70,000 (60,000 training, 10,000 test)
- **Features:** 28x28 Grayscale Images
- **Classes:** 10 (Digits 0-9, used only for visualization as the models are unsupervised)
- **Missing Values:** None

## Dependencies

### Python Dependencies
- Python 3.x
- NumPy, Matplotlib
- TensorFlow / Keras
- Jupyter Notebook / Google Colab

### LaTeX Dependencies
To compile the `Experiment_7.tex` file, the following packages must be installed in your TeX environment:
- `geometry`, `amsmath`, `amssymb`
- `graphicx`, `booktabs`, `array`, `float`
- `hyperref`, `enumitem`, `xcolor`
- `tikz` (with `positioning, arrows.meta, shapes.geometric, fit, calc`)

## Execution Instructions
1. Open `Lab7.ipynb` in Jupyter Notebook or Google Colab.
2. Ensure all Python dependencies are installed.
3. Run all cells sequentially from top to bottom.
