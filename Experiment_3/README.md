# Experiment 3: Convolutional Neural Networks for Image Classification

## Folder Structure
- `Lab3_Part1.ipynb`: Source code for Experiment 3.
- `Experiment_3.tex`: LaTeX source code for the experimental report.
- `README.md`: This documentation file.

## Dataset Information
- **Name:** CIFAR-10
- **Training Images:** 50,000
- **Testing Images:** 10,000
- **Classes:** 10 (Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck)
- **Image Size:** $32\times32\times3$

## Dependencies

### Python Dependencies
- Python 3.x
- TensorFlow / Keras
- NumPy, Matplotlib, Scikit-learn
- Jupyter Notebook / Google Colab

### LaTeX Dependencies
To compile the `Experiment_3.tex` file, the following packages must be installed in your TeX environment:
- `tikz` (with `shapes, fit, positioning, arrows`)
- `multirow`, `booktabs`, `rotating`, `tabularx`, `array`, `eqparbox`, `multicol`
- `xcolor`, `soul`, `framed`
- `graphicx`, `epstopdf`
- `amsmath`, `amssymb`, `mdwmath`, `mdwtab`, `mathtools`, `amsfonts`, `bm`, `newtxmath`
- `lipsum`, `siunitx`, `textcomp`, `gensymb`
- `cite`, `caption`, `subcaption`, `comment`, `footnote`, `enumitem`, `url`, `hyperref`, `fontenc`, `titlesec`, `geometry`

## Execution Instructions
1. Open `Lab3_Part1.ipynb` in Jupyter Notebook or Google Colab.
2. Ensure all Python dependencies are installed.
3. Mount Google Drive if using Colab to access the CIFAR-10 dataset batch files.
4. Run all cells sequentially from top to bottom.
