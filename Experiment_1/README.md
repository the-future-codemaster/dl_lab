# Experiment 1: Single Layer Perceptron for Binary Classification

## Folder Structure
- `Lab1_Part1.ipynb`: Source code for the first part of Experiment 1.
- `Lab1_Part2.ipynb`: Source code for the second part of Experiment 1.
- `Experiment_1.tex`: LaTeX source code for the experimental report.
- `Experiment_1.pdf`: Compiled PDF report of the experiment.
- `README.md`: This documentation file.

## Dataset Information
- **Name:** Banknote Authentication Dataset (UCI Machine Learning Repository)
- **Instances:** 1372
- **Features:** 4 Numerical Features (Variance, Skewness, Curtosis, Entropy)
- **Classes:** 2 (0 - Authentic, 1 - Forged)
- **Missing Values:** None

## Dependencies

### Python Dependencies
- Python 3.x
- NumPy, Pandas, Matplotlib, Scikit-learn
- Jupyter Notebook / Google Colab

### LaTeX Dependencies
To compile the `Experiment_1.tex` file, the following packages must be installed in your TeX environment:
- `tikz` (with `shapes, fit, positioning, arrows`)
- `multirow`, `booktabs`, `rotating`, `tabularx`, `array`, `eqparbox`, `multicol`
- `xcolor`, `soul`, `framed`
- `graphicx`, `epstopdf`
- `amsmath`, `amssymb`, `mdwmath`, `mdwtab`, `mathtools`, `amsfonts`, `bm`, `newtxmath`
- `lipsum`, `siunitx`, `textcomp`, `gensymb`
- `cite`, `caption`, `subcaption`, `comment`, `footnote`, `enumitem`, `url`, `hyperref`, `fontenc`, `titlesec`, `geometry`

## Execution Instructions
1. Open `Lab1_Part1.ipynb` and `Lab1_Part2.ipynb` in Jupyter Notebook or Google Colab.
2. Ensure all Python dependencies are installed.
3. Run all cells sequentially from top to bottom.
